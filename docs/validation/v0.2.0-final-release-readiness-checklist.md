- [ ] Confirm final `v0.2.0` scope remains internal advisory/source release only.
- [ ] Confirm no code, template, plugin, manifest, or archive content changes are required after `v0.2.0-rc1`.
- [ ] Confirm final release should reuse the accepted RC content or rebuild an equivalent final archive from the accepted release state.

- [ ] Run final archive smoke on the final archive before publishing.
- [ ] Verify final GitHub release asset hash after upload.
- [ ] Record final release metadata in `docs/validation/final-release-manifest.md`.
- [ ] Keep tenant-connected MCPs, hooks, credentials, and production actions disabled.
- [ ] Keep external/client/marketplace/proprietary distribution blocked unless separately approved.

## Distribution Decision

Allowed if final promotion is approved:

- Internal advisory use.
- Local workspace use.
- Source review.
- Template, sample, skill, and plugin install/load evaluation.

Blocked without separate approval:

- Client distribution.
- Proprietary or closed packaging.
- Marketplace publication.
- SAP-branded promotion.
- SAP documentation redistribution.
- Live SAP tenant validation claims.
- Production role, user, transport, configuration, hook, or MCP enablement.
- Fiscal/legal/security approval claims.

## Recommended Final Release Path

If the release owner accepts the same advisory scope as `v0.2.0-rc1`:

1. Create final tag `sap-codex-deliverables-v0.2.0`.
2. Build `sap-codex-deliverables-v0.2.0.zip` from the final tag.
3. Run archive smoke with expected SHA256.
4. Create a GitHub final release, not prerelease.
5. Verify uploaded asset digest and size.
6. Update `docs/validation/final-release-manifest.md`.

If any changes are required before final:

1. Keep `v0.2.0-rc1` as accepted RC evidence.
2. Apply fixes in a follow-up branch.
3. Run archive, asset, and desktop install/load smoke again.
4. Publish `v0.2.0-rc2` before final.

Proceed to final `v0.2.0` only if the release owner confirms that the final release preserves the accepted internal advisory RC scope and does not expand distribution or production claims.
