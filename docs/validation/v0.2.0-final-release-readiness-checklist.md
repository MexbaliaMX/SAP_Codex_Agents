Allowed if final promotion is approved:

- Internal advisory use.
- Local workspace use.
- Source review.
- Template, sample, skill, and plugin install/load evaluation.

Blocked without separate approval:

- Client distribution.
- Proprietary or closed packaging.
- Marketplace publication.
- SAP-branded promotion.
- SAP documentation redistribution.
- Live SAP tenant validation claims.
- Production role, user, transport, configuration, hook, or MCP enablement.
- Fiscal/legal/security approval claims.
