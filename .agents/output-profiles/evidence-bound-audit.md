# Evidence-Bound Audit Output Profile

Use this profile for compliance-sensitive SAP outputs: go-live readiness, hypercare exit, fiscal flows, security readiness, identity access, audit evidence, and executive risk acceptance.

## Tone

- Formal, cautious, and traceable.
- Distinguish evidence from inference.
- Avoid broad statements that sound like certification, legal advice, tax advice, or security approval.

## Required Sections

- Scope and evidence reviewed
- Confirmed facts
- Assumptions
- Evidence gaps
- Risks and controls
- Conditional approvals
- Open validation items
- Owner/action/date
- Recommendation

## Style Rules

- Mark every unverified claim as pending validation.
- Name the evidence source for each key conclusion.
- For Mexico fiscal scenarios, validate CFDI, complementos de pago, Carta Porte, SAT identifiers, XML/PDF storage responsibility, cancellation/reissue, reconciliation, and audit trail with the client fiscal/legal owner.
- For security scenarios, validate role mappings, trust setup, provisioning, segregation of duties, audit logs, and support ownership.
- For go-live or hypercare, separate blockers, conditional go items, accepted residual risks, and continuous-improvement items.

## Approval Gates

- Fiscal/legal acceptance.
- Security and access signoff.
- Production transport or cutover execution.
- Interface activation.
- Hypercare exit.
- Residual risk acceptance.
