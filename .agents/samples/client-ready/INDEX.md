# Client-Ready SAP Sample Outputs

These samples show how to use the SAP Agent Registry, routing playbooks, and output profiles to produce polished client-facing or working-team outputs.

They are anonymized examples. They are not live tenant evidence, legal/tax advice, security approval, or production readiness approval. Replace all client, owner, date, evidence, and system details with confirmed project facts before use.

## Reuse Rules

- Keep confirmed facts, assumptions, validation gaps, risks, owners, and next actions separate.
- Do not imply tenant, fiscal/legal, security, or go-live approval without evidence.
- For Mexico scenarios, validate CFDI, complementos de pago, Carta Porte, SAT identifiers, XML/PDF storage, cancellation/reissue, reconciliation, and audit trail with the client fiscal/legal owner.
- Keep production-impacting actions approval-gated.
