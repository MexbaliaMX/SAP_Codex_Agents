# Support

## Current Support Status

This repository is currently supported for internal advisory release-candidate review only.

Unsupported uses:

- Production use.
- Live SAP tenant operation.
- Client distribution.
- Marketplace publication.
- Proprietary packaging.
- Fiscal, legal, security, audit, or go-live approval claims.

## Reporting Documentation Defects

Open an issue for documentation defects and include:

- File path.
- Section or claim.
- Expected correction.
- Evidence source, if the correction affects SAP product behavior, licensing, roadmap, APIs, tenant behavior, or Mexico localization.

Do not include credentials, tenant URLs, client data, real fiscal XML, or user identifiers.

## Reporting Security Concerns

Follow `SECURITY.md`. Use a private owner channel when sensitive details are involved.

## Repository Support Versus SAP Product Support

This repository provides advisory assets, templates, skills, and validation records. It does not replace SAP product support, SAP documentation, SAP legal terms, implementation partner governance, client security approval, tax/legal review, or production operations approval.

Validate SAP behavior in the target landscape and current SAP documentation before relying on any guidance for implementation or operations.
